**«3301: Among Space»** — атмосферный научно-фантастический 2.5D-квест и инженерная головоломка в духе *Among Us* и *Cicada 3301*. Действие разворачивается на борту исследовательского крейсера **USSC HYPERION**, оказавшегося в режиме аварийного обесточивания посреди глубокого космоса.

Управляя бортинженером **Даниилом**, игроку предстоит исследовать многосекционный корабль с лучом тактического фонарика, разблокировать бронированные гермодвери, восстановить 5 критических инженерных узлов и синтезировать финальный криптографический мастер-ключ в Центральном Ядре.

---

## ✨ Ключевые особенности

- **🔦 Кастомный 2.5D Canvas-движок с трассировкой света и Y-сортировкой глубины:**
  - Честная геометрия корабля с непрозрачным внешним корпусом и детализированным открытым космосом вокруг (туманности, спиральная галактика, Сатурн с кольцами, газовый гигант со спутником, квазар с релятивистскими джетами, кометы и пояс астероидов).
  - Динамический отсекаемый стенами и закрытыми гермодверями конус тактического фонарика (`Raycasting Light Frustum`) в условиях аварийного блэкаута.
  - Полноценная 2.5D-перспектива для всех терминалов, стоек, реакторов, медкапсул и ровера с послойной Y-сортировкой (`sortY`), благодаря которой персонаж реалистично заходит **за** высокие объекты при обходе сверху и проходит **перед** ними снизу.
- **🚪 Бронированные гермодвери с мини-играми в стиле *Among Us*:**
  - Перед входом в каждый из 5 инженерных отсеков необходимо разблокировать гермозатвор (соединение проводов по цвету, разблокировка коллектора `1→8`, свайп ключ-карты, калибровка автоматов питания и активация гексагональных щитов), после чего массивная 2.5D-створка плавно поднимается вверх в потолочную балку.
- **🧠 5 многоступенчатых научно-инженерных узлов + Центральное Ядро:**
  1. **Узел I — Выставка авиации и авионики (Boeing 737-800):** балансировка бортовой электросети (`IDG-1`, `IDG-2`, `APU GEN`, `TR3`, `STANDBY`) для достижения целевой силы тока.
  2. **Узел II — Отсек хранения и переработки топлива:** криптоанализ перехваченной шифровки (шифр Цезаря / ROT) и выставление кодовых тумблеров.
  3. **Узел III — Ангар планетохода и робототехники:** программирование алгоритма обхода кратеров и препятствий для 6-колёсного марсохода с захватом образцов и возвратом на базу.
  4. **Узел IV — Зал управления реактором Токамак:** 4-фазный холодный ядерный синтез и нуклеосинтез изотопов с расчётом массовых и зарядовых чисел (`A / Z`).
  5. **Узел V — Панорамный Астрокупол:** спектральная классификация звёзд (`O, B, A, F, G, K, M`) по температуре, цвету и линиям поглощения.
  6. **Центральное Ядро — Синтез Ключа:** вычисление контрольной суммы всех узлов и генерация финального ключа `3301`.
- **🎚️ Два режима сложности:**
  - **«Изи»** — с инженерными подсказками и автозаполнением формулы контрольной суммы.
  - **«Для мальчиков»** — хардкорный режим без подсказок с ручным расчётом параметров и формул.
- **🎵 Процедурный генератор космо-эмбиента (Web Audio API):**
  - 5 переключаемых размеренных эмбиент-тем без внешних аудиофайлов (*Космический эмбиент*, *Крио-сон*, *Горизонт событий*, *Звёздная пыль*, *Сигнал пустоты*) + процедурные звуковые эффекты шагов, тумблеров, гермодверей и реактора.

## 🎮 Управление

| Действие | Управление |
| :--- | :--- |
| **Перемещение персонажа** | `W` `A` `S` `D` / Стрелки / **Левый клик мыши** по полу (авто-поиск пути `A*`) |
| **Направление фонарика** | Курсор мыши или вектор движения |
| **Взаимодействие с дверью / узлом** | Клавиша `E`, `Enter` или кнопка **`USE`** в правом нижнем углу (либо клик по объекту) |
| **Масштаб камеры (Zoom)** | Колёсико мыши (`Scroll`) |
| **Музыка и смена темы** | Панель переключателя тем `1–5` и кнопка звука в верхней панели HUD |
| **Выбор цвета скафандра** | Палитра цветов в верхней панели HUD |

## 🗺️ Архитектура корабля USSC HYPERION

- **Командный Центр // Серверное Ядро** *(центр корабля)* — точка старта, серверные стойки, тактические пульты и Центральное Ядро синтеза ключа.
- **Отсек 1 (СЗ): Выставка авиации** — чертежи и схемы Boeing 737-800, масштабные модели лайнеров и биплана на пьедесталах, конструкторский стол с разрезом турбовентиляторного двигателя и чёрный ящик.
- **Отсек 2 (СВ): Хранилище и переработка топлива** — спаренные криогенные силосы дейтерия и гидразина, манифольд высокого давления, ректификационная колонна и стеллаж топливных бочек.
- **Отсек 3 (ЮЗ): Ангар планетохода и робототехники** — 6-колёсный планетоход на зарядке, стенд осциллографа, верстак с разобранным манипулятором и печатными платами.
- **Отсек 4 (ЮВ): Зал управления Токамаком** — центральный тороидальный реактор холодного синтеза, криогенная стойка жидкого гелия и трёхуровневый главный пульт.
- **Отсек 5 (Север): Круглый Астрокупол** — обсерватория со спектрометрами, радиоинтерферометром и оптическими телескопами.
- **Медицинское отделение (Юг)** — био-регенерационные медкапсулы, центральный хирургический МРТ-томограф с автодоком, лаборатория фармакологии и криохранилище плазмы.

## 🛠️ Технологический стек

- **Frontend:** React 19, TypeScript, Tailwind CSS 4, Lucide Icons
- **Графика и физика:** HTML5 2D Canvas, кастомный 2.5D-рендерер, A*-навигация по сетке с обходом коллизий, трассировка лучей света (`Raycasting`)
- **Аудио:** Чистый процедурный синтез на базе браузерного `Web Audio API`
- **Сборка и тесты:** Vite, Node.js Test Runner (`node:test` + `tsx`)

## 🚀 Быстрый старт и локальный запуск

### 1. Клонирование и установка зависимостей

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ>
npm install
```

### 2. Запуск режима разработки

```bash
npm run dev
```

Приложение откроется по адресу `http://localhost:3000`.

### 3. Запуск модульных тестов и проверка типов

```bash
npm test
npm run lint
```

### 4. Сборка production-версии

```bash
npm run build
npm run preview
```
